What a save point holds

Honest about the rest.

Time Machine is not a magic undo. Every save point and every recovery says what came back and what you set again by hand.

What's saved

  • Code, including uncommitted changesYour commits and the edits you have not committed yet.
  • Files not in Git yetNew files you have not added to Git.
  • Config key namesPlus plain values you choose to keep. Never secret values.
  • Lockfile and environment fingerprintsSo you can see when dependencies or the runtime changed.
  • A verdict from your own checkThe result of the check you set up, like npm test.

What's not saved

  • Secret valuesOnly their key names and a fingerprint. You set the values again by hand.
  • DatabasesDatabase contents are not captured.
  • Deployed versionsA recovery makes a local branch. It does not change what is live.
  • Emails and paymentsWhat another service already did stays done.
  • Anything outside your projectTime Machine works inside your project folder.

Questions

Straight answers.

Including the ones where the answer is no.

Is this universal undo?

No. It brings back your project: code, files not in Git, config key names, and the lockfile. It does not bring back anything outside your project folder. Every recovery lists what was not restored.

Does it restore databases or deploys?

No. Database contents, deployed versions, emails and payments are not captured. A recovery makes a local branch and a recovery copy. It does not change what is live.

Does it store my passwords or API keys?

No. It stores the names of your settings and a fingerprint that shows when a value changed. Never the value itself. You set secret values again by hand, and the report tells you which ones.

Will it change my folder or my branch?

No. Checks run in a separate Git worktree. A recovery saves your current state first, then makes a new branch and a recovery copy. Switching to it is a step you take yourself.

Does it push, merge or deploy?

No. Nothing is pushed, merged or deployed. You decide what to do with a recovery branch.

What does PASS mean?

Your own check, like npm test, passed in a separate copy of that save point. It does not mean bug free. It means your check passed, and the verdict says how it was run.

How isolated is a check?

Checks run in host mode: a separate Git worktree on your machine, with a clean environment and a time limit. That is weaker than a container, and every verdict says so. With network: deny, checks run with no network through a sandbox. If no sandbox is available, the check does not run and the verdict is BLOCKED.

Can I install it today?

Not from npm yet. You can run it from source with Node 22 or newer, pnpm and Git. The Mac app is in development.

Which agents does it work with?

Claude Code hooks work today. Any agent that speaks MCP can use the MCP server. Git and file changes are captured no matter which tool made them.

Is it the same as Git?

No. It uses Git and adds what a commit does not keep: uncommitted work, files not in Git, config key names, and dependency and environment fingerprints. Then it checks which versions actually work.

Is this related to Apple's Time Machine?

No. This is an independent project, not affiliated with or endorsed by Apple. Apple's Time Machine backs up your Mac. This checks and rewinds your projects.
