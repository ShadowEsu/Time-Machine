Time Machine

Early access. The tm CLI works today. Not on npm yet.

Your AI agent broke it. Get back the version that passed your tests.

$ tm find-good
cp-0004  FAIL  The check failed with exit code 1.
cp-0003  PASS  The check passed.

Time Machine saves your project before Claude Code acts. It runs your own tests on each save point in a separate copy, then brings back the newest one that passes. Your folder is never touched.

See it run

Why

Built-in rewind skips the shell.

"Checkpointing does not track files modified by Bash commands."

Claude Code docs, Checkpointing

So when an agent runs rm, mv or sed -i, that rewind cannot bring the files back. Time Machine saves before risky shell commands, outside your project folder.

How it works

Save. Check. Bring back.

  1. Save

    Claude Code hooks save before each prompt and before risky commands. Save points live outside your project, with a Git bundle.

  2. Check

    Each save point is rebuilt in a separate Git worktree and your own check runs, for example npm test. One verdict: PASS or FAIL.

  3. Bring back

    The newest save point that passes comes back on a new branch. Nothing is pushed, merged or deployed.

What does not come back: secret values, databases, deployed versions and external services. Every report lists them.

Questions

Short answers.

Does it replace Git?

No. It works next to Git. A recovery is a new branch you can inspect before you merge it yourself.

Does it store my secrets?

No values, only key names. Known secret patterns are filtered from captured files and logs. Screening cannot recognize every secret, so review what you capture.

Does it undo database changes or deploys?

No. Databases, deployed versions and external services are not captured. Every report says so.

When can I use it?

The CLI works today from source. It is not on npm yet. Waitlist members get one email when it is, and when the Mac app is ready.

How does the waitlist order work?

After you join you get a personal link. Each friend who joins with it moves you up. Order: most friends joined first, then earliest signup. That is the whole rule.

What will it cost?

Nothing is for sale. The CLI will be free and MIT licensed. Restores will never be behind a paywall.
