How it works

Save. Check. Find. Recover.

Save points live outside your project. Checks run in a separate copy. Your folder and your branch stay as they are.

  1. 01

    Save

    Make a save point before a risky change. It keeps your code, including changes you have not committed.

    tm checkpoint -m "note"
  2. 02

    Check

    Time Machine rebuilds a save point in a separate folder and runs your own check, like npm test. It records the verdict.

    tm verify cp-0003
  3. 03

    Find the last working version

    It walks back from your newest save point and stops at the first one that passes.

    tm find-good
  4. 04

    Recover on a new branch

    It saves your current state first, then makes a new branch. Nothing is pushed, merged or deployed.

    tm recover cp-0003

What a save point holds

Clear about what it keeps.

Time Machine is not a magic undo. Every save point says what it holds and what it does not.

What it saves

  • Code, including uncommitted changesYour commits and the edits you have not committed yet.
  • Files not in Git yetNew files you have not added to Git.
  • Config key namesPlus plain values you choose to keep. Never secret values.
  • Dependency and environment fingerprintsSo you can see when a lockfile or runtime changed.
  • A verdict from your own checkThe result of the check you set up, like npm test.

What it does not save

  • Secret valuesOnly their key names. You set the values again by hand.
  • DatabasesDatabase contents are not captured.
  • Deployed versionsA recovery makes a local branch. It does not change what is live.
  • Emails and paymentsWhat another service already did stays done.
  • Anything outside your projectTime Machine works inside your project folder.

Every save point and every recovery lists what was not restored.

For agents

A save point before your agent acts.

Agents move fast and touch many files. These two pieces will let them save and check on their own.

  • Claude Code hooks

    Works today

    A save point before each agent turn and before risky commands. When the agent stops, a check runs, and the agent hears about it if a working version just broke.

  • MCP server

    Works today

    Save, check, find the last working version and recover, as tools for any MCP client.

Set up with tm hook install and claude mcp add timemachine -- tm mcp. Every command also takes --json.
