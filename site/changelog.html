Changelog

What changed in Time Machine, newest first. Each entry links to its pull request on GitHub. Planned work is not listed here.

22 October 2026

  1. See Time Machine save before a risky command

    When Time Machine saves before a risky command such as git reset --hard, Claude Code now shows you one line: "Time Machine saved cp-0007 before git reset --hard." Prompts and the end of a turn stay quiet. tm demo now ends with the next step for your own project. When tm init finds no test command, it says so plainly. tm status tells you, and the plugin's setup skill, what is missing.

  2. Save points from the same minute are easy to tell apart

    When two save points share a minute, the app shows their seconds as well. The save point number breaks any remaining tie.

    PR #26

  3. Stop a check or a search

    Long checks and searches for the last working version now have a Stop button. A stopped check never changes a verdict.

    PR #26

  4. A first-time tip and a clearer add-project step

    The first time a verdict appears, a short tip explains Works, Broken and Not checked yet. You can dismiss it. Adding a project now labels each step and the check field more clearly.

    PR #26

  5. A calmer home page, and install steps for Claude Code

    The first screen now shows the headline, the waitlist and the real recording, with no typing effect or opening screen. A new install.md lists the setup steps in a form Claude Code can follow.

    PR #26

  6. Time Machine in your browser with tm ui

    tm ui opens the same app screens in your browser, served from your own computer at 127.0.0.1. It uses the same engine and save points as the CLI. Nothing is hosted, and each launch gets a private session key.

    PR #25

21 October 2026

  1. One warm dark look, and a new recording

    The site and the app now share one warm dark look, and the app starts in dark mode. The home page has a new 68-second recording of the real Mac app, with captions and chapters.

    PR #24

  2. Easier to read and move around the site

    Body text is larger, captions are easier to read, and header links are easier to hit. Links within a page stop below the sticky header, and pressing a chapter brings the video into view.

    PR #22 and PR #23

20 October 2026

  1. Clearer recovery screens in the Mac app

    The recovery screens are quieter, with clearer type, and open on your history. Muted text has more contrast, and the recovery limits can be reached with the keyboard.

    PR #19 and PR #20

  2. A real recovery on the home page

    The home page shows a captioned recording of the real Mac app bringing back a working version, with chapters and a transcript. The video downloads nothing until you press play.

    PR #20 and PR #21

  3. Install steps you can follow today

    The site lists the real commands to install from source, and what they need: Node 22 or newer and Git. It also shows how long clone to finished demo took in two timed runs.

    PR #17 and PR #18

  4. Hooks work from a source install

    tm hook install now points the Claude Code hooks at your installed tm, not at an npm package that is not published yet. Reinstalling replaces old Time Machine hook lines and keeps other tools’ hooks. After a recovery, the advice now says to keep working in the recovery copy, so restored files are not lost.

    PR #16

  5. Fair limits on the waitlist

    Signups, referral lookups and visit counts are limited per client. Too many requests get a clear answer to try again later.

    PR #15

  6. Claude Code turns show live in the Mac app

    A save point made by the Claude Code hooks in another terminal now appears in the open Mac app as it happens, titled with your prompt. The site’s API also refuses requests that fake where they come from.

    PR #14

  7. Safer recovery and a steadier Mac app

    Every recovery lists each thing it could not bring back. You can save before your project’s first commit, and undo still works after you delete the recovery copy by hand. The Mac app runs one copy at a time and stops a running check when you quit.

    PR #13

19 October 2026

  1. Try the rewind on the home page

    An interactive illustration lets you turn a dial back to the save point that passed. A second view shows the same steps as app screens. Both are illustrations and open no files.

    PR #11 and PR #12

  2. Accessibility pass in the Mac app

    Keyboard focus stays inside dialogs and goes back where it was when they close. Status changes are announced to screen readers, and the main buttons are easier to hit.

    PR #10

  3. Waitlist storage and an honest comparison

    Waitlist signups are kept in their own database schema. The public key can only call three fixed functions and cannot read the tables. The home page adds a table comparing Claude Code’s rewind, Git and Time Machine.

    PR #9

18 October 2026

  1. The public site

    The first public site: one promise, real tm output and a waitlist with personal referral links. Real Mac app screens and a three-step walkthrough for people who don’t write code followed the same day. The opening screen and typing effect added that day were removed on 22 October.

    PR #2, PR #3, PR #6, PR #7 and PR #8

  2. Signups wait as pending, and the site sends no email

    A signup is saved as pending and unconfirmed. The site never sends email. Preston writes to the list himself.

    PR #6

  3. Mac app launch screen and packaging

    The Mac app has a launch screen and smoother transitions. Builds use a stable self-signed package. They are not signed by Apple.

    PR #6 and PR #7

  4. A first run that actually checks

    tm init now guesses the install step from your lockfile, so the first check can install dependencies and run. On a real open source project, init to a checked recovery branch took 54 to 82 seconds in two timed runs.

    PR #4

  5. The npm package is ready, not published

    The npm package, timetm, installs and runs the demo from a clean folder. It is not on npm yet.

    PR #3

  6. The first release

    The save, check and recover engine, the tm CLI, the Mac app and this site, under the MIT license. Tests run in CI on macOS and Linux with Node 22 and 24.

    PR #1
