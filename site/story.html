What it does

Save. Check. Bring back.

  • Save. Before each prompt, and before risky commands like rm -rf or git reset --hard.
  • Check. Your own test runs in a separate copy, with the network off.
  • Bring back. The newest save point that works, on a new branch. Your folder is never touched.

Why would you need that? Here is a normal morning.
