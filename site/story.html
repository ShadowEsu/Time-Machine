What it does

Save. Check. Bring back.

  • Save. Before each prompt, and before risky commands like rm -rf or git reset --hard.
  • Check. Your own test runs in a separate copy, with the network off when a sandbox is available.
  • Bring back. The newest save point that works, on a new branch. Your folder is never touched.

It saves where you are first, then builds tm/recover/cp-0003 in a separate copy. Your folder and branch are never touched. Nothing is pushed, merged or deployed.

And it tells you what it could not bring back. Secret values from config files like .env are never stored, only key names and a fingerprint. Databases and deployed versions are not captured.
