Install from source Not on npm yet

Thanks for getting Time Machine.
Just a few steps left.

It runs on macOS and Linux and needs Node 22 and Git. It isn’t on npm yet, so you build it from source once.

Windows isn’t supported yet.

  1. 1 
    cd ~
git clone https://github.com/ShadowEsu/Time-Machine.git && cd Time-Machine
pnpm install && pnpm build
npm install -g ./packages/cli

    Copy the install command.

    No pnpm? Run npm install -g pnpm first.

  2. 2

    Paste it into Terminal and press Return. The first run downloads and builds, so give it a few minutes.

    It builds in ~/Time-Machine. Keep that folder: tm runs from it.

  3. 3 
    tm ui

    In your project, run tm ui.

    It opens in your browser at 127.0.0.1; your project never leaves your computer.
