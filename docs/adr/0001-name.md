# ADR 0001: Product name and package name

Date: 14 October 2026. Status: accepted by the team.

## Decision

- The product and company name stays **Time Machine**.
- The npm package is **`timetm`** (free on npm on 14 October 2026). Users run `npx timetm init`.
- The installed command is **`tm`**.

## Alternatives considered

- Renaming before launch (Undoable, Lastworking, Goodstate, Oopsback). Rejected by the team.
- Bare npm names `tm`, `timemachine`, `time-machine`. All taken by other people.

## Known risk, accepted

Apple holds US registration 3,583,786 for TIME MACHINE, covering software "to protect and back up computer files, and to recover and restore deleted and overwritten files". Apple has defended its marks against small companies before. The team accepts this risk.

Mitigations we keep anyway:

- Never use Apple's clock-with-arrow icon, star field imagery, SF Pro, or Apple's exact colors.
- Footer and FAQ say "Not affiliated with Apple Inc."
- A trademark attorney's opinion is still recommended before a paid launch.

## Cost of changing later

A rename after launch means a new npm package, a new domain, and lost search history. The `tm` command can stay the same.
