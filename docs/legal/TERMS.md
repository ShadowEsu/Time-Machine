## 2. What Time Machine does

Time Machine records save points of a software project on your computer. A save point can include your Git history, files you choose, the names of settings you choose, and the definition of your environment. Time Machine can run a check you set up, find the most recent save point that passed, and prepare a recovery branch and a recovery copy.

## 3. What Time Machine does not do

Please read this part. Time Machine is not universal undo.

- It only brings back what it captured. Every save point lists what was not captured and what needs manual recovery.
- It never stores secret values. You must restore keys, passwords and tokens yourself.
- It does not undo emails, payments, deploys, or changes to outside services or production databases.
- A check passing means your check passed. It does not mean your project has no bugs.
- It is not a full disk backup. Keep your own backups.
- It does not push, merge or deploy anything. You decide what to do with a recovery branch.
