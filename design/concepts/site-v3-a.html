02  How it works

Save. Check. Bring back.

Three steps, one engine. The CLI, the hooks and the MCP server all call the same functions, so they never disagree.

  1. i.

    Save

    Before each prompt, and before risky commands like rm -rf or git reset --hard. Save points live outside your project folder.

    $ tm checkpoint -m "Added dark mode"
  2. ii.

    Check

    Your own test runs in a separate copy, with the network off. Newest first, until one passes.

    $ tm find-good
  cp-0006  FAIL
  cp-0005  FAIL
  cp-0004  FAIL
  cp-0003  PASS
  3. iii.

    Bring back

    The newest save point that works, on a new branch. Your folder is never touched. Nothing is pushed, merged or deployed.

    $ tm recover cp-0003
  Branch  tm/recover/cp-0003
  Saved first  cp-0007
