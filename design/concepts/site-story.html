Introduction

Git remembers your code. Time Machine remembers whether it worked. Every change you or your agents make becomes a save point, with the files, settings and environment around it. Each one is checked in a safe copy, so going back is never a guess.

How it works

Four steps. One click.

01

Save

A save point before every agent turn and every risky command. Automatically.

02

Check

Rebuild any save point in a separate copy and run your check. Your folder is never touched.

03

Rewind

Walks back newest first and stops at the first version that works.

04

Recover

A new branch from that version, with a report of what came back and what didn't.

FAQ

Questions, answered.

01How is this different from Git?

Git keeps code you committed. Time Machine also keeps uncommitted work, chosen files, settings and the environment, and it knows which versions actually pass your check.

02Claude Code and Cursor already have rewind. Why this?

Built-in rewinds only see their own agent's file edits and miss shell commands. Time Machine works across agents, saves before risky commands, and proves a version works before you use it.

03Will it touch my project or push anything?

No. Checks run in a separate copy. Recovering makes a local branch and saves your current state first. It never pushes, merges or deploys.

04What about my secrets?

Secret values are never stored. Time Machine keeps key names and tells you when one changed, so you know what to re-enter.

05Do I need Docker?

No. Checks run in a separate copy on your Mac. If Docker or Apple's container tool is installed, it uses them for stronger isolation and says so.

06Is this Apple's Time Machine?

No. This Time Machine is an independent project for builders and is not affiliated with Apple Inc.
